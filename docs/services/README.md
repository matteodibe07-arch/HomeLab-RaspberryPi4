# HomeLab Services

This directory contains documentation for the services running on my Raspberry Pi 4 HomeLab.

## Available Services

- **[Pi-hole](pihole.md):** Network-level DNS filtering.
- **[Nextcloud](nextcloud.md):** Self-hosted file storage and photo management.
- **[Tailscale](tailscale.md):** Secure remote connectivity.

Each document describes the purpose of the service, its role in the HomeLab, and relevant security considerations.

The documentation will be expanded as the configuration evolves.
