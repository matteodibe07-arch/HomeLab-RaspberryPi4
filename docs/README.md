# Documentation

This directory contains the technical documentation for my Raspberry Pi 4 HomeLab.

The purpose of this documentation is to describe the infrastructure, explain how its components interact, and keep track of configurations, technical decisions, and future improvements.

## Documentation Structure

- **[Architecture](architecture.md):** Overview of the hardware, operating system, and services running on the HomeLab.
- **[Networking](networking.md):** Network topology, IP addressing, DNS configuration, and remote connectivity.
- **[Services](services/):** Service-specific documentation, including configuration details, administration, and troubleshooting.

## Documentation Principles

The documentation is updated as the infrastructure evolves. Configuration details should reflect the actual environment, while sensitive information such as passwords, private keys, authentication tokens, and other secrets must never be published.
